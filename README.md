# Noir Note — Minimal Workspace & Thought Organizer
> **0% Blue Charcoal Theme • 15pt Pastel Yellow Typography • Micro-Spring Luxury Motion**

A clean, distraction-free workspace designed for deep thinking, studying, and documentation.

---

## Key Highlights

### 1. 🌑 Eye-Comfort Charcoal Gray (`#18181a`)
- **Zero Blue/Cyan/Lavender Saturation**: Pure neutral grays designed for all-day reading without eye strain.
- **Warm Pastel Yellow Typography**: 15pt high-legibility sans-serif text with soft golden headings.

### 2. 🪄 100% Focused Zen Environment
- **Isolated Hover Reveals**: The bottom cell toolbar and footer actions (Export MD, Backup, Restore) remain completely hidden until your cursor specifically reaches their zones.
- **Dedicated Dashboard**: The main view shows only your page cards. Hovering or clicking on page cards does NOT trigger any unwanted popups or buttons.
- **Solid Sleek "Add Page" Button**: Clean hairline border without any dotted outlines or visual clutter.

### 3. 🧱 7 Modular Block Types & 2-Column Side-by-Side Layout
- **2-Columns Block**: Place independent markdown, code, notes, tasks, or toggles side by side.
- **Width Toggle (`◫`)**: Instantly toggle any block between full-width (1 column) and half-width (2 columns).
- **Block Types**:
  1. **Markdown**: Formatted headers, bold/italic, lists, quotes, tables.
  2. **Code**: Multi-language syntax formatting with one-click copy.
  3. **Tasks**: Interactive checklists with progress tracking.
  4. **Note**: Key takeaways and summary callouts.
  5. **Toggle**: Collapsible Q&A blocks for active recall and self-testing.
  6. **Subpage**: Nested page cards for organizing sub-topics.

### 4. 💎 Luxury Physics-Based Motion
- Smooth Apple/Linear cubic-bezier spring curves (`cubic-bezier(0.16, 1, 0.3, 1)`).
- Micro-interactions on hover, click, and transition without jarring jumps.
